# Workbench

Notes that don't need another command-line flag yet.

## Export first, inspect later

Keep the inventory next to the build notes, outside the repository. An export
is a snapshot of the editor's asset registry, not a manifest for packaging.
Moving or renaming assets after exporting makes it stale.

For bigger projects, start with one folder under `/Game`. A project-wide report
usually has enough naming differences to hide the one thing you're looking for.

## Sample names

Nightglass is the workspace; Paper Lantern is the map inside it. Neither name
changes how the checker runs. The fixture notes explain the two deliberate
prefix mistakes.

## Loose ends

- Folder-specific prefix overrides might be useful for vendor content.
- A CSV output mode would make reports easier to share.
- No automatic renaming. References and redirectors need a separate workflow.
